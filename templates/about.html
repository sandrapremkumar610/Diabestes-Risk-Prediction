About this project

Introduction

The Diabetes Risk Prediction System is an MCA academic project. It uses supervised machine learning to place a person in a lower-risk or higher-risk group for diabetes from eight health measurements.

Objectives

  • Accept health information through a simple web form.
  • Process the input and predict the risk group with a trained model.
  • Show the prediction, a model score and general health recommendations.
  • Show the model's real evaluation results.

Dataset

The Pima Indians Diabetes Dataset has 768 records and 8 input features (Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age) plus the Outcome (0 = non-diabetic, 1 = diabetic).

In Glucose, BloodPressure, SkinThickness, Insulin and BMI, a value of 0 is not a real measurement. These zeros are treated as missing and filled with the median of the training data.

Algorithm

Four algorithms are trained and compared: Logistic Regression, Decision Tree, Random Forest and Support Vector Machine (SVM). Each uses a Scikit-learn pipeline for median imputation and standard scaling. The dataset is split into 80% training data and 20% testing data using stratification. All trained models and their evaluation metrics are saved using Joblib and JSON respectively.

Technologies

Python, Pandas, NumPy, Scikit-learn, Joblib, Flask, HTML and CSS.

Limitations

  • The dataset contains only historical records of Pima Indian women aged 21 and above, so it does not represent every population, men or younger people.
  • With only 768 records, results vary with the train-test split.
  • Many records had missing values replaced by the median, which adds uncertainty.
  • The model score is not a clinically calibrated probability.
  • A lower prediction does not rule out diabetes, and a higher prediction does not confirm it.

This is an educational project and is not clinically validated. It must not be used to diagnose, treat or rule out any medical condition. Please consult a healthcare professional for medical advice.
